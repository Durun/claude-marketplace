# gankooyaji

Claude の回答が曖昧なとき、プロンプト直上に頑固オヤジが出てツッコミを入れる Mod です。

## 動き

1. `turn.complete` で回答本文を受け取る（40 文字未満は見送る）
2. `$.model.complete` の haiku に読ませ、曖昧な語があれば 1 行のツッコミを返させる。問題にした語は haiku が `**「面」**` の形で囲む
3. `ui.render` の `AbovePrompt` に、壁を突き破って乱入するオヤジのドット絵とツッコミを描く。指摘が複数の点にまたがったときは、乱入の前に顔のカットインを挟む
4. オヤジが叫び終えると、右端の下からババアがゆっくり昇ってきて、たしなめつつ語の意味を解説する
5. 次のターンが始まると消える

## ババア

haiku の出力 2 行目がババアのセリフです。「まあ落ち着いて。」で始め、オヤジが問題にした語を回答の文脈から読み解いて言い直します。
2 行目が無ければババアは出ません。

- オヤジの最後の文字が地の色に落ち着いてから 6 コマ置いて、顔が下から 2 コマに 1 ピクセルずつ昇り、オヤジと同じ高さで止まる
- 昇り切ってから喋り始める。文字送りと口パクはオヤジと同じ
- セリフはオヤジのセリフの下に右寄せで置く。「まあ落ち着いて。」の直後で改行する
- 文字は白から青 `#6b9bff` へ、囲まれた語は水色 `#7dd3fc` へ落ちる

## カットイン

挙げた語が 2 つ以上あるか、指摘が 2 点以上にまたがったときに入ります。

- 語の数は `**「面」**` の形の強調を数えて決めます。末尾の叫びには鉤括弧が無いので数に入りません
- 指摘の数は haiku が行頭に `!!` を出して知らせます。印は落として描きます

語が 1 つで、引っかかった点も 1 つだけのときは、いつもの登場のままです。

カットインは帯いっぱいの幅で描き、27×18 ドットの怒った顔を中央に置きます。
顔は帯の上下いっぱいまで続けます。目だけを切り出すと、宙に浮いて見えるためです。
8 コマ出してから、壁を破る登場へ移ります。

- 0 コマ目: 全面が白く飛ぶ
- 1〜7 コマ目: 顔が出て、その左右を線が一方向に流れる

線は絵として持たず、列と行から決まる位相をコマで進めて引きます。
顔の外の空きに合わせて勝手に伸びるので、顔を描き直しても線は付いてきます。

カットインのあとの登場は普段より激しくします。

- 壁は溜めを飛ばして 1 コマで抜け、穴は上下の端まで広がる
- 顔は定位置を 3 セル行き過ぎてから戻り、着いた反動でもう一度跳ねる
- 破片は 11 個に増え、上下へ広く速く散る

## 乱入の見せ方

顔は 14×16 ドットを `▀` の上下 2 ピクセルに畳んで描きます。
アニメーションは `$.clock.every` の 45ms ごとに 1 コマ進みます。

- 0 コマ目: 壁は無傷。顔は壁の裏に隠れている
- 1〜2 コマ目: 壁の中央から外へひびが広がる
- 3 コマ目: 中央が抜け、顔が 8 セル飛び出して 2 ピクセル浮く。破片が穴から前方へ飛ぶ
- 4〜8 コマ目: 1 ピクセルずつ落ちながら残り 7 セルを詰めて急減速する
- 9 コマ目以降: 着地して喋り始める。セリフは 1 コマ 1 文字ずつ増え、その間 1 コマおきに口が開く
- 3〜12 コマ目: 破片が放物線を描いて右下へ落ちていく
- セリフを出し切ったら口を閉じ、破れた壁を左に残して静止

セリフの `** **` で囲まれたところは色を変えて描きます。囲みの記号は落とすので、文字送りの速さは見た目の文字数で決まります。
文字は出たばかりのコマが明るい白で、4 コマかけて地の色へ落ち着きます。囲まれた語は黄 `#ffd166`、それ以外は赤 `#ff6b6b` に落ちます。
日本語の太字の字形を持たない書体が多いので、強調は太さではなく色で分けます。

顔は定位置へ向かって減速するだけで、行き過ぎも揺り返しもしません。
縦は飛び出しの勢いで 2 ピクセル浮き、1 ピクセルずつ落ちて着きます。
`▀` は 1 セルに 2 ピクセルを持つので、縦はセルの半分の幅で動かせます。
止まるコマ数はセリフの長さで決まります。
破片は顔より手前を飛び、1 コマあたり 0.8 セルの加速度で落ちます。

端末で見るには次を実行します。

```
node --experimental-strip-types preview.ts                  # 全コマを並べる
node --experimental-strip-types preview.ts --play           # 45ms 送りで 3 回再生する
node --experimental-strip-types preview.ts --play "ないぜ！"  # セリフを変えて再生する
node --experimental-strip-types preview.ts --play "ないぜ！" "まあ落ち着いて。"  # ババアのセリフも変えて再生する
node --experimental-strip-types preview.ts --play --intense  # カットイン付きの激しい登場で再生する
```

判定する対象は 11 点です。
主語の欠落、指す先の分からない指示語、具体性を欠いた翻訳調の名詞と動詞、造語、「〜ない」だけの否定、濁した断定。
助詞の抜けと誤り、誰がやるのか消えた受け身、例外を書かない逃げの前置き、1 文への詰め込み、二重否定。
転用された語は「面」「印」「正典」「塗り」「穴」「効く」「落ちる」「詰める」を例として渡し、同じ質の語を探させます。

## 入れ方

Function Hooks は早期アクセスなので、有効化が必要です。

```
# ~/.claude/settings.json
{ "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }
```

```
/plugin marketplace add Durun/claude-marketplace
/plugin install gankooyaji@durun-toolbox
```

## 手を入れるとき

型は生成物なので、セッションで `/plugin-types` を実行して `.claude/types` に置き直してから触ります。

```
claude plugin validate .
node_modules/.bin/tsc -p tsconfig.json
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude --plugin-dir . --debug
```

描画されないときは `--debug` のログを見ます。props が型と違うと画面には何も出ず、`ui.render (AbovePrompt): a hook returned a tree that does not validate` の行だけが残ります。
