# claude-run

Claude が走って柱を跳び越える。Chrome の恐竜と同じ遊び方で、絵は 3D で作る。

## 遊び方

`/dino` で面が開く。`j` か `[ 跳ぶ ]` の押下で跳ぶ。柱に当たると止まり、`r` でもう一度。`Esc` で閉じる。

途中からカメラが走者の周りをゆっくり回り始める。真横から見ているうちは柱までの距離が
そのまま画面の距離になるが、回り込むと奥行きが混ざる。画角が変わっても同じ間合いで跳べるかどうかが、
このゲームの山になる。

## 絵の作り方

- 場面は距離関数で持ち、光線を進めて色を決める
- 1 画素あたり 3x3 の光線を飛ばして平均する
- 平均した色は 20 数色へ丸める。陰影はなめらかなまま、粒が立つ
- 1 セルに上下 2 画素を半ブロックで詰めるので、縦の解像度は行数の 2 倍になる

84x22 セル、1 画素 2x2 の光線で 1 コマ約 7 ms。表示の更新は `$.ui.blit` で面だけ差し替える。

## 手元で確かめる

```sh
npx tsx preview.ts 200        # 端末にコマを流す。1 コマの所要時間も出る
npx tsx shot.ts 600 shot.png  # 指定のコマを PNG に落とす
```

自動操作で走るので、当たり判定と画角の変化を通しで見られる。

## 必要なもの

Function Hooks を有効にした Claude Code。

```sh
export CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1
```
