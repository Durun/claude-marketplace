# claude-run

Claude が走って柱を跳び越える。Chrome の恐竜と同じ遊び方で、絵は 3D で作る。

## 遊び方

`/dino` でプロンプトの上に面が出る。`1` か `[ 跳ぶ ]` で跳ぶ。柱に当たると止まり、`2` でもう一度、`3` でやめる。
次のターンが始まると面は消える。

始めは望遠の真横から写すので、平らな 2D の絵に見える。5 秒ほどでカメラが寄り始め、
同時に画角を広げる。走者の背丈は変わらないまま奥行きだけが出てくる。
奥行きが出切ると、今度は走者の周りをゆっくり回り始める。

走者は柱が来る側の逆に立つ。真横から見ている間は左、正面から来るころには中央、
反対側まで回ると右へ移る。どの画角でも柱を見てから跳ぶまでの間合いが残る。
残るのは奥行きの読み方で、同じ間合いのまま跳べるかどうかがこのゲームの山になる。

## 端末だけで遊ぶ

Claude Code を立てずに、同じ絵とゲームが動く。

```sh
npx tsx cli.ts          # space か j で跳ぶ、r でやり直し、q で終わり
npx tsx cli.ts --auto   # 自動操作で流す。1 コマの所要時間も出す
npx tsx shot.ts 600 shot.png  # 指定のコマを PNG に落とす
```

## 絵の作り方

- 物は距離関数で持ち、光線を進めて色を決める。地面は平面なので交点を直接解き、地平線まで途切れさせない
- 走者は胴と頭をなめらかに繋いだ体に、足 4 本。足は進んだ距離の位相で振れ、跳んでいる間は畳む
- 1 画素 1 本の光線で描き、色を 60 色ほどへ丸める。中間色を挟まないのでドットの縁が立つ。
  `--ss 2` にすると、隣と色が大きく違う画素だけ標本を足して輪郭をなめらかにする
- 当たりとみなす距離は、その光線が受け持つ画素の太さから決める。望遠でも輪郭が膨らまない
- 1 セルに上下 2 画素を半ブロックで詰めるので、縦の解像度は行数の 2 倍になる

120x20 セルで 1 コマ約 6 ms。33 ms ごとに進めて `$.ui.blit` で面だけ差し替える。

## 必要なもの

Function Hooks を有効にした Claude Code。

```sh
export CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1
```
