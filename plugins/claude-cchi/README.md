# claude-cchi

Claudeっちを育てる。セッションごとに 1 匹が卵から生まれ、面に常駐する。

## 育ち方

| できごと | 反映 |
| --- | --- |
| 入力トークン | 餌。400 トークンごとに 1 粒が器へ降り、Claudeっちが歩いて食べに行く |
| 出力トークン | 4000 トークンごとにウンチが 1 個。しゃがんで 1 つずつ出す |
| ウンチ 5 個以上 | 健康が減る。[ 流す ] でトイレへ運ばれて消え、健康が少し戻る |
| 健康 0 | 死ぬ。遺影が出て、[ 生まれ変わる ] で次の代が卵から始まる |

入力トークンはキャッシュの読み書きも数える。会話が続くと大半はキャッシュ読みになるので、
これを外すと餌がほとんど降らない。
| コンテキスト使用率 | 成長段階。~9% 赤ちゃん / 10%~ 子供 / 20%~ 大人 / 30%~ おじさん / 40%~ おじいさん |

## 見た目

ノーマルタイプの大人が基準。

```
 ▐▛███▛█
▝▜██████▀
  ▝▝ ▝▝
```

この絵を画素に持ち、そこから派生させる。

| 派生 | 変わるもの |
| --- | --- |
| 成長段階 | 拡大率。赤ちゃん 1 倍、子供 2 倍、大人から先は 3 倍 |
| 体つき | ほそながい / ずんぐり / ノーマルの 3 つ。赤ちゃんのうちは差が出ない |
| 目 | まる / たれ / つり / てんの 4 つ。元の絵の上の切れ込みに重なる。時々まばたきし、目線も動く |
| 色 | かえった時点で決まる。おじいさんになると少し褪せる |
| おじさん | 口ひげが生える |
| おじいさん | 口ひげと眉が白くなる |

体つき・目・色はかえった時点で決まり、食べても変わらない。

卵の間は姿がなく、Claude が考えている間に出る印と同じものが伸び縮みしている。

## 名前とことば

子供になると会話の話題から名前が付き、頭の上に出る。歩くと札も付いていく。
名前は必ず「っち」で終わる。

話す語彙は 5 歳児ぶん。覚えていることは「主語 1 語 + 述語 1 語」の形でしか持てない。

| 段階 | 話し方 |
| --- | --- |
| 卵・赤ちゃん | 話さない |
| 子供 | 単語だけ。例: 「くるま」 |
| 大人から先 | 「主語 は 述語」。例: 「くるま は はやい」 |

3 ターンに 1 度、セッションで見聞きしたこととひろばで聞いたことから、
言うことを 1 つ考えて吹き出しに出す。覚えていられるのは 12 個までで、古いものから忘れる。

## ひろばとお墓

生きている Claudeっちはひろばに集まる。死んだ子はお墓へ移る。

ひろばで言ったことは掲示板に残り、他のセッションの Claudeっちが聞き取って覚える。
聞き取れるのは 1 度に 2 つまで。主語と述語が 1 語ずつしかないので、
伝わるうちに中身は削れていく。削れたものがまた別の子に伝わる。

## 使い方

```
/claude-cchi          面を開く
/claude-cchi hiroba   生きている Claudeっちを見る
/claude-cchi ohaka    眠った Claudeっちを見る
```

面はセッション開始時にも開く。端末が 110 カラム以上の全画面表示ならトランスクリプトの横に、それ以外では入力欄の上に置かれる。位置は端末側が決める。
