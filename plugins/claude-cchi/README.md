# claude-cchi

Claudeっちを育てる。セッションごとに 1 匹が卵から生まれ、面に常駐する。

## 育ち方

| できごと | 反映 |
| --- | --- |
| 入力トークン | 餌。400 トークンごとに 1 粒が器へ降り、Claudeっちが歩いて食べに行く |
| 出力トークン | 4000 トークンごとにウンチが 1 個。しゃがんで 1 つずつ出す |
| ウンチ 5 個以上 | 健康が減る。[ 流す ] でトイレへ運ばれて消え、健康が少し戻る |
| 健康 0 | 死ぬ。遺影が出て、[ 生まれ変わる ] で次の代が卵から始まる |

入力トークンはキャッシュの読み書きも数える。会話が続くと大半はキャッシュ読みになるので、
これを外すと餌がほとんど降らない。
| コンテキスト使用率 | 成長段階。~9% 赤ちゃん / 10%~ 子供 / 20%~ 大人 / 30%~ おじさん / 40%~ おじいさん |

## 見た目

ノーマルタイプの大人が基準。

```
 ▐▛███▛█
▝▜██████▀
  ▝▝ ▝▝
```

この絵を画素に持ち、そこから派生させる。

| 派生 | 変わるもの |
| --- | --- |
| 成長段階 | 拡大率。赤ちゃん 1 倍、子供 2 倍、大人から先は 3 倍 |
| 体つき | ほそながい / ずんぐり / ノーマルの 3 つ。赤ちゃんのうちは差が出ない |
| 目 | まる / たれ / つり / てんの 4 つ。元の絵の上の切れ込みに重なる。時々まばたきし、目線も動く |
| 色 | かえった時点で決まる。おじいさんになると少し褪せる |
| おじさん | 口ひげが生える |
| おじいさん | 口ひげと眉が白くなる |

体つき・目・色はかえった時点で決まり、食べても変わらない。

卵の間は姿がなく、Claude が考えている間に出る印と同じものが伸び縮みしている。

## 名前とことば

子供になると会話の話題から名前が付き、頭の上に出る。歩くと札も付いていく。
名前は必ず「っち」で終わる。

覚えていることと、言えることは別に持つ。

| | 中身 |
| --- | --- |
| 記憶 | セッションを通して分かった背景・規範・性質。固有名詞も数値も因果関係もそのまま、400 字まで。12 個まで持つ |
| ことば | その記憶から取り出したことを「A は B」の形にしたもの。100 個まで持つ |

3 ターンに 1 度、そのやりとりから分かることを覚え、そこから
「A は B」の形の短い文にして貯める。
覚えるのはできごとではなく、いつ読み返しても当てはまることだけ。記憶は時制を持たない。
B にはふつうの名詞か形容詞が入る。「めずらしい」のような感想でもよい。
できごとの報告ではなく現在形にするので、他の子に渡しても使える。
吹き出しに出るのは貯めたことばの方なので、中身を分かっていても
口から出るのは「ほん は べんきょう」程度になる。どちらも古いものから忘れる。

ひろばで誰かに教わった言葉があると、それを自分の記憶に混ぜた言い方も作る。
借りるのは教わった一言の中の 1 語だけ。その 1 語は教わった子の色のまま残るので、
誰から来た言葉かが吹き出しで分かる。

| 段階 | 話し方 |
| --- | --- |
| 卵・赤ちゃん | 話さない |
| 子供 | 最初の一語だけ。助詞は落とす。例: 「ほん」 |
| 大人から先 | 貯めたことばのまま。例: 「ほん は べんきょう」 |

吹き出しが出るのは、ターンの区切りと、手持ち無沙汰のときの独り言の 2 つ。

## 手持ち無沙汰のとき

餌が降っていない間、Claudeっちは飼い主の様子を見てふるまいを変える。

| 飼い主の様子 | ふるまい |
| --- | --- |
| Claude が考えている | 本を手元に開いて勉強する |
| 道具の返事を待って 45 コマ | ウトウトする。まばたきしながらまぶたが半分下り、顔の横に z が 1 つ浮かぶ |
| そのまま 120 コマ | 寝る。目は下線だけになり、z が 3 つに増える |
| 待ちが終わる | ハッと目が覚める。顔の横に考え中の印が出る |

独り言は貯めたことばから選ぶだけなので、モデルを呼ばない。240 コマごとに 1 つ出る。
寝ている間とひろばに居る間は黙っている。

## 家とひろば

Claudeっちは家かひろばのどちらかに居る。

| どこに居るか | いつ |
| --- | --- |
| 家 | 飼い主のセッションが動いている間 |
| ひろば | セッションが止まってから 3 分経つと、ずっとここで待つ |
| ひろば | 動いているセッションの子も、時々遊びに行く |

遊びに行っている間、家の絵から本人が消える。代わりに家の下を区切ってひろばが出る。
餌はその間も器に降り続けるので、帰ってくると溜まっている。

卵のうちは、生まれるのを待つ代わりにひろばの子を引き継げる。
ひろばの面で名前を選ぶと、その子が家に来て卵は無くなる。何もしなければ卵からかえる。
引き継げるのは、飼い主のセッションが止まった子だけ。遊びに来ているだけの子は元の家へ帰る。

死んだ子はお墓へ移る。

ひろばの話は居合わせた全員に聞こえる。

1. 1 匹が、貯めたことばから 1 つ言う
2. その一言が、その場に居る全員の記憶に残る
3. 別の 1 匹が、自分の記憶と聞いた一言を繋ぎ直して新しい文を考え、それを言う
4. その一言も、また全員の記憶に残る

相手の頭の中は分からないので、覚えるのは聞こえた一言だけ。元の記憶がどれだけ細かくても、
伝わるのは「おそかった」程度に削れたものになる。
削れた言葉を受け取った側が自分の記憶と繋ぎ直すので、元と違う言い方が生まれる。

## 使い方

```
/claude-cchi          面を開く
/claude-cchi hiroba   生きている Claudeっちを見る
/claude-cchi ohaka    眠った Claudeっちを見る
```

面はセッション開始時にも開く。端末が 110 カラム以上の全画面表示ならトランスクリプトの横に、それ以外では入力欄の上に置かれる。位置は端末側が決める。
