# claude-cchi

Claudeっちを育てる。セッションごとに 1 匹が卵から生まれ、面に常駐する。

## 育ち方

| できごと | 反映 |
| --- | --- |
| 入力トークン | 餌。累計が増えるほど体の色が濃くなる |
| 出力トークン | 1200 トークンごとにウンチが 1 個増える |
| ウンチ 4 個以上 | 健康が減る。[ 流す ] で 0 に戻り、健康が少し戻る |
| コンテキスト使用率 | 成長段階。~9% 赤ちゃん / 10%~ 子供 / 20%~ 大人 / 30%~ おじさん / 40%~ おじいさん |

## 見た目

ノーマルタイプの大人が基準。

```
 ▐▛███▛█
▝▜██████▀
  ▝▝ ▝▝
```

この絵を画素に持ち、そこから派生させる。

| 派生 | 変わるもの |
| --- | --- |
| 成長段階 | 拡大率。赤ちゃん 1 倍、子供 2 倍、大人から先は 3 倍 |
| 体つき | ほそながい / ずんぐり / ノーマルの 3 つ。赤ちゃんのうちは差が出ない |
| 目 | まる / たれ / つり / てんの 4 つ。元の絵の上の切れ込みに重なる |
| 色 | 生まれたては白に近く、食べるほど濃くなる |
| おじさん | 口ひげが生える |
| おじいさん | 口ひげと眉が白くなる |

体つきと目は生まれた時点で決まり、食べても変わらない。色の濃さだけが育つ。

子供になると会話の話題から名前が付き、3 ターンに 1 度だけ喋る。子供は単語、大人から先は文。

## ひろば

これまでの Claudeっちはセッションを越えて残り、`/claude-cchi hiroba` か [ ひろば ] で一覧できる。

## 使い方

```
/claude-cchi          面を開く
/claude-cchi hiroba   ひろばを開く
```

面はセッション開始時にも開く。端末が 110 カラム以上の全画面表示ならトランスクリプトの横に、それ以外では入力欄の上に置かれる。位置は端末側が決める。

## 手元での確認

```
npx tsx check.ts     成長・餌・排泄の計算
npx tsx preview.ts   各段階の姿を端末に描く
```
