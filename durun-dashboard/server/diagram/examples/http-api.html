HTTP通信

POST /api/notes/{noteId}/share

メモの共有リンクを1本発行する。認証が必要で、メモの持ち主だけが呼べる。

パラメータ

名前位置型必須説明
noteIdpathinteger必須notes.id
expiresInDaysbody (JSON)integer (1〜30)任意リンクの有効日数。省略すると 7

レスポンス

ステータス条件ボディ
201共有リンクを発行したJSON。url と expiresAt を含む
400expiresInDays が 1〜30 の整数でない空
401ログインしていない空
404メモが無い、または持ち主が違う空。どちらなのかを区別できる情報を返さない
409メモが published でない空
503データベース障害空。Retry-After: 10

実例

POST /api/notes/482/share HTTP/1.1
Host: notes.example.com
Content-Type: application/json
Cookie: session=e3b0c442

{ "expiresInDays": 7 }

HTTP/1.1 201 Created
Content-Type: application/json
Cache-Control: no-store

{ "url": "https://notes.example.com/s/Zk3pVx9Qe2Lm8TnHs4YdWa", "expiresAt": "2026-10-21T09:00:00Z" }
