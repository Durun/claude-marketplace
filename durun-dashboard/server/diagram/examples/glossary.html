例: 用語集ホバー

本文に出てくる用語へマウスを乗せると説明が出る。編集するのは末尾の用語集テーブルだけでよい。

本文

メモの所有者は、共有リンクを発行して他人にメモを見せる。リンクの末尾にあるトークンが、開くメモを決める。 トークンは share_links に保存し、有効期限が切れるか、所有者が失効させると使えなくなる。

メモの状態は draft、published、archived のどれかで、共有リンクで開けるのは published だけである。 貼った画像はオブジェクトストレージに置き、本文には画像の場所だけを書く。

用語

用語一覧を開く
用語説明
共有リンク（リンク）メモを他人に見せるために発行する URL。末尾のトークンで、開くメモが決まる
トークン共有リンクごとに発行する、推測できない乱数。share_links に保存して照合する
有効期限共有リンクを使える期限（expires_at）。過ぎたトークンでは、メモを開けない
失効有効期限の前に、共有リンクを使えなくすること。share_links の行を消すと失効する
draft / published / archivedメモの status がとる値。draft は書き途中、published は共有リンクで開ける状態、archived は一覧から外した状態
オブジェクトストレージメモに貼った画像を置く保存先。本文は PostgreSQL に、画像はここに分けて置く
所有者（owner）メモを書いた利用者。notes.owner_id が指す users の行で、編集と共有リンクの発行ができる
