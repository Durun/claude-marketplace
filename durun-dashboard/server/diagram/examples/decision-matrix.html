メモ本文の保存形式の選定

結論: Markdown のまま保存し、表示のたびに HTML へ変換する。決め手は、変換規則の修正が保存済みのメモにもそのまま効くこと。

案規則の修正表示の速さ原文の扱い決め手
Markdown を保存 採用 ◎ 保存済みにも効く△ 表示のたびに変換◎ そのまま返せる サニタイズの修正を、全メモへ即座に反映できる
HTML を保存 △ 全メモの再変換が要る◎ 保存済みを返すだけ○ 原文を別の列に持つ なし
却下した案の詳細

HTML を保存する案は、変換規則やサニタイズを直すたびに、保存済みの全メモを再変換する必要がある。再変換が終わるまでは、古い規則で作った HTML が表示され続ける。
