意思決定

D1. 共有リンクのトークンは推測できない乱数にして share_links に保存する

token は 16 バイトの乱数から作り、有効期限と一緒に share_links へ保存する。署名付き URL は使わない。

利点
  • 発行後でも、share_links の行を消せばリンクを失効できる
  • token からメモの ID も有効期限も読み取れない
代償
  • 共有リンクを開くたびに share_links を 1 回引く
却下案: 署名付き URL

署名付き URL は、署名の鍵を替えない限り、発行済みのリンクを失効させられない。鍵を替えると有効なリンクもすべて無効になるため、却下した。

未決: 共有リンクの有効期限の既定を 7 日にするか 30 日にするか。プロダクトオーナーの確認待ち。
