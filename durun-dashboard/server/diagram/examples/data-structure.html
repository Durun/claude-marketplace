データ構造

リレーショナル: テーブルカード + 多重度

users
  • id PK
  • name
1 ──── N
note は
user に属する
notes
  • id PK
  • owner_id FK → users
  • status draft | published | archived
1 ──── N
share_link は
note に属する
share_links（新規）
  • token PK
  • note_id FK → notes
  • expires_at

入れ子構造: TypeScript 型で示す

type NoteResponse = {
  id: number;                 // notes.id
  title: string;
  status: "draft" | "published" | "archived";
  updatedAt: string;          // ISO 8601 (UTC)
  share?: {                   // 発行済みの共有リンクがあるときだけ付く
    url: string;              // /s/{token} を含む完全な URL
    expiresAt: string;        // share_links.expires_at
  };
};
