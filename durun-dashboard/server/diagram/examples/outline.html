例: 右端の目次

画面右端の目盛りに見出しの階層が出る。マウスを乗せると見出し名の一覧へ開き、読んでいる節が濃く出る。

置き方

資料の書き手が書くのは <body> の中身だけである。 目次のために本文へ書くことは何もない。 ダッシュボードが base.css と base.js を資料へ入れ、読み込み時に h2 と h3 から目次が組み立てられる。 id の無い見出しには h-1 のような id が振られ、目次の各行がその見出しへのリンクになる。

ダッシュボードが base.js の <script> を <body> の末尾に入れるのは、 本文より先に走ると見出しがまだ無く、目次を組み立てられないためである。

出ない条件

画面が狭いとき

本文の幅は 60rem で中央に置かれるため、画面が 76rem 未満だと目次が本文へ重なる。 重ねて出すより出さない方が読みやすいので、その幅では目次自体を隠す。

見出しが少ないとき

見出しが 3 個未満の文書では、目次があっても本文を追う助けにならないので組み立てない。

用語集との併用

文書末の用語集（id="glossary"）にある見出しは付録なので目次へ出さない。 用語集ホバーと同時に使ってよい。どちらも base.css と base.js だけで動く。

確認のしかた

この例をブラウザで開き、右端へマウスを寄せる。スクロールすると濃い目盛りが下へ移る。 目次の行をクリックすると、その見出しまで移動する。
