例: 意思決定と未決事項の参照番号

意思決定は D 番号、未決事項は U 番号で通し番号を振る。本文にその番号を書くだけで、定義箇所へのリンクと、定義箇所の見た目を縮小したホバーが付く。

本文からの参照

共有リンクのトークンは D1 のとおり乱数にする。共有リンクの API 仕様は U1 と U2 が決まってから確定する。 定義が無い番号（X9）は素のテキストのままで、リンクもホバーも付かない。

意思決定

D1 共有リンクのトークンは推測できない乱数にして保存する

他人がリンクを推測して別のメモを開くのを防ぐため、トークンは乱数にする。照合のため、share_links に保存する。

利点
  • 行を消せば、有効期限の前でも共有を止められる
代償
  • 共有リンクを開くたびに share_links を 1 回引く
却下案: 署名付き URL

署名付き URL は発行後に失効させられないため却下した。

D2 メモ本文は Markdown のまま保存し、表示のたびに HTML へ変換する

変換後の HTML は保存しない。変換の仕様を直しても、保存したデータを作り直さずに済むため。

未決事項

2 件ある。着手を止めるのは U1 だけで、U2 は暫定解を置いて並行して確認する。

U2 共有リンクの有効期限の既定を 7 日にするか 30 日にするか 7 日で実装する（U1 の結論に依存しない） プロダクトオーナー
