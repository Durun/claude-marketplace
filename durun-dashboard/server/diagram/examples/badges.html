意味色の対応

色は文書全体で同じ意味に固定する。色だけに意味を担わせず、ラベルの語で意味が分かるようにする。

バッジ意味ラベルの例
採用採用、正常、完了採用 / 正常 / 利点 / 実装済み
禁止禁止、異常、却下禁止 / 異常 / 代償 / 未確定
新規今回の変更点、新規追加新規 / 追記 / 本設計
変更既存物の変更変更 / 執筆中
マージ済みマージ済みPRPRの状態にだけ使う（pr-stack.html）
対象外スコープ外、既存のまま、区分の表示対象外 / 既存 / 自動 / 手動

チップ列

並びに沿って、どれが対象でどこで止まるかを示す。値そのものを見せるので丸バッジにしない。破線や取り消し線に意味を持たせたら、必ず凡例を添える。

凡例: 青の実線 照合に当たる / 実線 通過 / 破線 対象外 / 赤の実線 打ち切り / 取り消し線 実行されない
