## 作業ルール
- 実装したらコミットする。コミットしてよいかを確認しない。
- OS ごとに違う処理は `server/platform.ts` に置き、ほかのコードからは必ずそこを経由する。OS ごとの実装には、どの OS でも走るテストを `test/platform.test.ts` に足す。
- 外部の情報源（gh、JIRA、Notion、haiku など、読むのに時間がかかるもの）から読む値は、`server/cache.ts` の `cached` を通して覚え、サーバーを起動し直した後もすぐ返す。スナップショットに載せる値は `peekCached` で読む。外部に書き込んだら、`forgetCached` でその値を忘れる。
- 画面でその値を読むときは `useCached` を使い、load が受け取る `fresh` を API に渡す。`fresh` は「更新」のボタンで読み直したときに真になり、サーバーに覚えた値を使わず読み直させる。
- キャッシュする値の形を変えたら、キーの名前も変える。ファイルに残った古い形の値を、新しいコードに返さないため。
