## ノードと描画

| 用語 | 定義 | 識別子 |
|---|---|---|
| 前置きのスクリプト | `web.cef` がページの `<head>` の直後に差し込む CSP とスクリプト。CSP でネットワークとファイルの読み込みを禁じ、倍率を CSS の `zoom` で掛け、ページの `mmSetTime` には `data` だけを渡す | `mm_nodes_cef::inject` |
| 静止のページ | 時刻によらず同じ画面のページ。時刻を 0 に揃え、パラメータの組ごとに 1 回だけ描く | `web.cef` の `static` |
| モックの矩形 | CEF のホストが無い環境で、`web.cef` がページの代わりに描く、ページと `data` で決まる色の矩形 | `WebCefKind::mock` |
| 中間の形式 | 合成で使うテクスチャの形式（`Rgba16Float`、premultiplied、線形） | `mm_gpu::FRAME_FORMAT` |

## 文字

| 用語 | 定義 | 識別子 |
|---|---|---|
| ルビの注記 | 文字列の中にふりがなを書く青空文庫の書き方（`｜親文字《ふりがな》`、漢字の並びの直後の `《ふりがな》`） | `mm_text_api::parse_ruby` |
| 親文字 / ふりがな | ルビを付ける文字の並び / その上に描く読み | `RubySpan::base`、`RubySpan::ruby` |
| 文節の折り返し | 語と文節の切れ目でだけ行を折ること。日本語は BudouX の分け方 | `LineBreak::Phrase` |
| 縁取り | 字の外側に付ける線。色と太さ | `TextStroke` |

## パック

| 用語 | 定義 | 識別子 |
|---|---|---|
| web の部品 | `web.cef` で描く HTML のページ 1 つ。パックの `web/` に置く | `packs/*/web/*.html` |
| web 手順 | web の部品を `web.cef` のレイヤーとして置くマクロの手順。テーマを `data.theme` で渡す | `Step::Web`、`WebStep` |
