## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| 名前つきの移行 | 整数のバージョン（v9 で止める）の後の、プロジェクトのデータの形の変更。1 つの移行を 1 つのファイルに書き、済ませた移行の名前の組をデータに持つ | `src/migrations/YYYYMMDD_<題>.rs`、`Project.migrations` |
| 移行の記録 | 保存の先頭に書く、整数のバージョンと済ませた名前つきの移行の組 | `version_stamp`、`copy_stamp`、`is_current` |
| 生成物 | 元から作り直すファイル。衝突したら手で直さず作り直す | `Cargo.lock`、`ops.json`、`scripts/regen.sh` |
| 揺れるテスト / 隔離 | 再試行で通ったテスト / 揺れるテストをゲートから外して別に実行すること（ラベル `flaky` の issue が開いている間） | `scripts/nextest-ci.sh`、`[profile.quarantine]` |
| ホスト / ランチャー | 別のプロセスで描く実行ファイル / それを起こし、標準入出力の 1 行の JSON で要求と応答をやり取りするアプリ側 | `mm-host-cef serve`、`CefLauncher`、`PipeHost` |
| 共有テクスチャ | プロセスをまたいで NT ハンドルで渡す GPU のテクスチャ | `host/share.rs` |
| 読み捨てる（応答を） | 期限切れにした要求の応答が後から届いたとき、数えて捨てる | `PipeHost::stale` |

## 時間とシーケンス

| 用語 | 定義 | 識別子 |
|---|---|---|
| OTIO | OpenTimelineIO。タイムラインの交換形式 | `mm_doc::otio`、`mm otio` |
| トラック（OTIO の） | OTIO の `Track`。Mixer のトラックと分けて、必ず「OTIO の」を付ける | `Track.1` |
| 項目（OTIO の） | OTIO のトラックの子（`Clip`、`Gap`、`Transition`） | — |
| メタデータ（OTIO の） | OTIO に無い値を `metadata["movie-maker"]` に入れたもの。OTIO の値と食い違えば OTIO の値に従う | `NAMESPACE`、`CutMeta`、`TrackMeta`、`META_VERSION` |
| 配置の長さ | タイムラインの上のカットの長さ `(out - in) / speed`。外したカットは 0 | — |
| 往復 | 書き出して取り込むと元のデータに戻ること | — |

## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| きっかけのバス / 対象のバス | ダッキングで、鳴ると他を下げるバス / 下げられるバス | `Ducking.trigger`、`Ducking.targets` |
| 短期ラウドネス / 統合ラウドネス | 直近 3 秒 / 測り始めからの BS.1770 のラウドネス。短期は 3 秒の窓が埋まるまで、統合は 400 ms まで出さない | `MasterReading::short_term_lufs`、`integrated_lufs` |
| dBFS | デジタルのフルスケールを 0 とする dB | `Ducking.threshold_db` |

## 書き出しと納品

| 用語 | 定義 | 識別子 |
|---|---|---|
| 字幕の焼き込み | 字幕を `text` ノードのレイヤーにして、書き出しとプレビューのフレームに描くこと。フィクスチャにフレーム番号を書く「焼き込む」と分ける | `delivery.burn_in_captions`、`mm_export::burn_in_captions` |
| 字幕の帯 | 字幕を置く矩形。「帯」単体は Timeline のレイヤーの範囲を指すので、必ず「字幕の」を付ける | `CaptionPlacement` |
| 字幕の置き場所 | sequence のレイヤーの、字幕の帯の下端の中央と幅 | `setCaption`、`Layer.framing` |
| 最上段 | コンポジションのレイヤーの並びの一番上（最後に描く） | — |
