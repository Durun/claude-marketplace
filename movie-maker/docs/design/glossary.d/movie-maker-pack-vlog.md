## パック

| 用語 | 定義 | 識別子 |
|---|---|---|
| パック | ある作り方（vlog など）の決まりを、基盤のコードの外にデータとして持つフォルダー。基盤はパックを知らない | `packs/<名前>/`、`mm_pack::Pack` |
| マクロ | 引数を受けて操作の列を作る、パックの手順の組。展開すると 1 つのトランザクションになる | `macros/*.json`、`MacroDef` |
| テンプレート（パックの） | 空のプロジェクトに適用するマクロ（コンポジション、レンダーターゲット）。形はマクロと同じ | `templates/*.json`、`MacroKind::Template` |
| 手順 | マクロの 1 段。操作 1 つか、文字のスタイルで文字を置く指定 | `Step`、`TextStep` |
| 展開する | マクロの引数を埋め、手順を操作の列（1 つのトランザクション）にすること | `mm_pack::expand`、`mm pack expand` |
| 例の引数 | 検査がマクロを試しに展開して適用するための引数 | `MacroDef::example` |
| 検査（パックの） | パックの形、参照、色を確かめ、例の引数で展開して適用してみること。操作の検証とは別 | `mm_pack::check`、`mm pack check` |
| テーマ（パックの） | パックの色の名前、書体、動きの長さの上限、画面。`ui/theme`（パネルの見た目）とは別 | `packs/*/theme.json`、`mm_pack::Theme` |
| 画面（テーマの） | テーマが決める本編とショートのコンポジションの幅、高さ、fps。画布とは別 | `theme.json` の `canvas`、`short` |
| 文字のスタイル | 字幕やラベルなど、文字の置き方の決まり 1 つ。字の大きさと色、位置、プレート、出る・消える動き。シェーピングに渡す `TextStyle` はその一部 | `styles.json`、`TextStyleSpec` |
| プレート | 文字の下に敷く角丸の地（縁、ずらした影、傾き。テロップの座布団）。`shader.wgsl` で描き、レイヤーの ID は `<文字のレイヤーの ID>.plate` | `PlateSpec`、`mm-pack/src/sticker.rs` |
| 表記の置き換え | 誤認識の語を正しい表記にする表。`corrections` を持つ文字のスタイルが適用する。修正（文字起こしの）とは別 | `corrections.json` |
| 見積もりのシェーパー | フォントを読まず、全角を 1 字、半角を 0.6 字として文字の塊の大きさを見積もるシェーパー。検査が使う | `EstimateShaper` |
| エピソード | Vlog の 1 本（ep04 など） | `templates/episode.json` |
| セクションの見出し | 節の見出しを左上に出す文字のスタイルとマクロ。同じ時刻にチャプターのマーカーを置く | `section` |

## 置き換えた語

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 当てる | マクロの操作、テンプレート、表記の置き換え | 適用する |
| 札 | 文字の下に敷く地 / 左上のセクションの表示 | プレート / セクションの見出し |
| 文字の型 | `styles.json` の 1 項目 | 文字のスタイル |
| 雛形 | `templates/` | テンプレート |
| 回 | Vlog の 1 本 | エピソード |
| 表記の直し | `corrections.json` | 表記の置き換え |
| 版の番号 | `pack.json` の `version` | バージョン |
| 題 | マクロの `title` / 節の名前 | 表示名 / 見出し |
