## レイヤーの見える範囲と音のフェード

| 用語 | 定義 | 識別子 |
|---|---|---|
| レイヤーの座標 | 変形の前の、コンポジションの画素での位置。切り抜きとマスクとアンカーが使う。素材を `fit: none` で置けば素材の画素 | `Transform.anchor`、`Layer.crop`、`Mask.rect` |
| 切り抜き | レイヤーの画像の縁から上下左右を内側へ削る幅 | `Crop`、`Layer.crop`、`crop.left` |
| 角丸の矩形のマスク | 左上、大きさ、角の半径で決まるマスクの形 | `MaskRect`、`Mask.rect`、`addMask` |
| 音のフェード | レイヤーの先頭か末尾で、長さと曲線で音量に掛ける倍率。音量のキーフレームとは別に持つ | `Fade`、`LayerAudio.fade_in`、`fade_out` |
| フェードの曲線 | 振幅の直線、等パワー、dB の直線のどれか | `FadeCurve` |
