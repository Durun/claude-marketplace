# 用語集

設計書、コメント、CLI の文言で使う正式な用語。左が正式な用語、右が定義と対応するコードの識別子。
新しく書くコードと設計書は、最初からこの用語を使う。用語を足すときは、段階ごとの用語のクリーンアップ（[進め方](15-roadmap.md#段階ごとの手順)）で表に足す。

## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| インターフェース | トレイトと型だけで、実装を持たない境界。実装のクレートと分ける | `mm-*-api` |
| API クレート | インターフェースだけを持つクレート | `crates/mm-*-api` |
| 実装のクレート | 1 つのインターフェースを 1 つの方式で実装するクレート | `mm-<領域>-<方式>` |
| 共通実装 | 複数の実装のクレートが共有する、インターフェースに出さない実装 | `mm-gpu` |
| 組み立て | 設定から実装を選んで `Engine` を作ること | `mm_runtime::assemble`、`Engine` |
| レジストリ | ノードの種類を名前で引く表 | `mm_runtime::registry` |
| 一式 | 組み立てが選んだ実装の組 | `Engine` のフィールド |
| 領域 | 並行開発の単位。書いてよいディレクトリの組 | `docs/areas.toml` |
| 操作経路 | 操作を発行した経路（CLI、MCP、アプリのサーフェスと WebView） | `mm_ops::Entry` |
| エントリーポイント | プログラムやシェーダーの開始点 | `main` |
| バックエンド | GPU API やデコーダーなど、差し替えられる下側の実装 | D3D12、Vulkan、d3d12va、cuvid |
| コア | クラッシュしうるものを外に出した後に残る、1 プロセスで動く中心 | `mm-render` ほか |
| 層 | 依存の方向で分けた区分（基礎 → インターフェース → 実装 → 組み立て） | — |
| バインディング / ブリッジ | C の API を Rust から呼ぶための宣言 / C++ を C に見せる薄い層 | `mm-color-ocio/src/ffi.rs`、`native/mm_ocio.cpp` |
| ラッパー | 別の型を包んで別のインターフェースに見せる型 | `mm-decode-d3d12va/src/wrap.rs` |
| ハンドル | 型を消して持ち回る参照 | `GpuHelper::as_any` |
| 契約 | インターフェースが約束する振る舞い。契約テストで確かめる | `mm_testkit::*::contract()` |
| モック | 契約テストと縦の 1 本に使う、テスト用の実装 | `mm-testkit` |
| フィクスチャ | テストに使う素材、プロジェクトのデータ、プロジェクト | `fixtures/`、`mm_testkit::fixtures` |
| 期待画像 | 描いた結果を比べる基準の画像（ゴールデン） | `xtask golden-update` |
| ハーネス | テストが共通に使う足回り | `mm_testkit::node::contract` |
| 試作 | 難所を確かめる小さな実装 | `spikes/`、`docs/design/spikes/` |
| 難所 | 段階 0 で先に確かめた、設計を左右する技術的な不確かさ | 15-roadmap |
| 縦の 1 本 | 素材を切って文字を載せ、音を付けて書き出す、最小の通し | `mm_testkit::fixtures` |
| フォールバック | 既定の方式が失敗したときに切り替える代替 | `mm_runtime::decode_select` |
| 計装 | 何を測るかの決まりと、測る仕組み | `mm-trace` |
| 予算 | 計装の項目ごとの上限。超えたら性能のテストが失敗する | 17-instrumentation |
| シナリオ | `mm perf run` が回す計測の筋書き | `mm perf run <シナリオ>` |

## プロジェクトのデータと操作

| 用語 | 定義 | 識別子 |
|---|---|---|
| プロジェクトのデータ | 編集対象の全体。設計書とは別。`Project` を根とする JSON | `mm_doc::Project` |
| バージョン | プロジェクトのデータとスキーマのバージョン。操作を 1 つ適用するたびに、データのバージョン番号が 1 進む | `doc_version`、`mm_doc::migrate` |
| 名前付きバージョン | 名前を付けて残したプロジェクトのデータのバージョン | `versions/`、`mm export` |
| 操作 | プロジェクトのデータを変える編集の 1 単位。引数、検証、適用、逆操作、`touches` を持つ | `mm_ops::Op`、`mm op` |
| 逆操作 | 操作を打ち消す操作。取り消しに使う | `Apply::inverse` |
| トランザクション | 複数の操作を 1 つとして適用し、途中で失敗したら全部戻す単位 | `TxnRecord`、`txns` |
| 取り消し / やり直し | トランザクション単位の undo / redo | `mm undo`、`mm redo`、`undo_stack` |
| 適用する | 操作をプロジェクトのデータに反映すること | `Apply::apply` |
| 拒否する | 検証に通らない操作を `Err` で返すこと | `MmError::InvalidArgument`、`Locked`、`Conflict` |
| フィールド | 構造体や JSON の項目 | — |
| バリアント | enum の枝 | `Op` の各バリアント |
| パス（パラメータの） | レイヤーかカットの中でパラメータを指す `.` 区切りの道 | `ParamRef` |
| コンテンツハッシュ | 素材の内容から計算した、キャッシュのキーになるハッシュ | `Asset.contentHash` |
| 付属ファイル | 取り込みツールが素材ごとに書く JSON | `mm-ingest-api` |

## ノードと描画

| 用語 | 定義 | 識別子 |
|---|---|---|
| ノード | 入力パラメータを受け取り、時刻ごとに映像と音を返すもの | `Node`、`mm-node-api` |
| ノードの種類 | ノードの型。撮影素材、文字、単色、コンポジション、シーケンスなど | `NodeKind` |
| コンテキスト | 描画や音の評価に渡す実行時の環境 | `FrameCx`、`AudioCx`、GPU のコンテキスト |
| レンダラー | コンポジションと時刻からフレームを描くもの | `Renderer`、`mm-render` |
| フレーム | 映像の 1 枚 | `Frame`、`FrameRef` |
| 画像 | 画素の並び。フレームや中間結果 | `Image` |
| サーフェス | ウィンドウに張る描画先 | `wgpu::Surface`、`MmSurface` |
| プレーン | YUV の画像を構成する面（Y、UV） | NV12、P010 |
| プール | 使い終わったテクスチャを戻して使い回す置き場 | `mm-decode-d3d12va/shared/pool.rs` |
| リングバッファ / スロット | 固定個数の枠を順に使い回すバッファとその 1 枠 | `mm-decode-cuvid/src/share.rs` |
| 借用 | GPU のフレームを `submit` が終わるまで借りること | `GpuHelper::import`（RFC 0001） |
| 画布 | ノードの種類が描く先の大きさ（コンポジションの画素に倍率を掛けたもの） | `FrameCx::size` |
| 領域（画像の） | ノードの種類の画像が存在する矩形。レンダラーは画布と違う大きさの画像をここに置く | `region_of_definition`、`FrameCx::region`（RFC 0008） |
| 面積平均 | 縮小で、出力の 1 画素が覆う元の画素を平均すること。合成で 1 回だけ、線形の光で行う | `compose.wgsl` の `taps` |
| 先行するリードバック | 読み戻しの提出と完了の待ちを分け、数フレーム後に待つこと | `WgpuGpu::begin_readback` / `finish_readback` |
| デバイスの消失 | GPU のデバイスが使えなくなること。レンダラーは次のフレームの前にコンテキストごと作り直す | `GpuContext::is_lost`、`recreate` |
| 寿命 | 借用したフレームが有効な期間 | `KEPT_RENDERED_FRAMES` |
| 提出 | GPU のキューへコマンドを送ること | `Queue::submit` |
| リードバック | GPU の結果を CPU へ読むこと | `GpuHelper::download` |
| 先読みの描画 | 再生より先に描いてキャッシュに置くこと | `Scheduler` |
| ヒット率 | キャッシュが当たった割合 | 17-instrumentation |
| フラグ | 真偽の状態 | — |
| ガード | ドロップされたときに後片付けをする値 | `GpuFrameTexture` |
| ウィンドウ | OS の窓 | Tauri の `Window` |

## デコードと色

| 用語 | 定義 | 識別子 |
|---|---|---|
| デコード / デコーダー | 符号化された映像と音を画素と PCM にすること / するもの | `Decoder`、`mm-decode-*` |
| エンコード / エンコーダー | 画素と PCM を符号化すること / するもの | `Encoder`、`mm-encode-*` |
| 索引（PTS の） | パケットを全部読んで作った PTS → フレーム番号の表 | `timeline.rs` |
| 作業色空間 | 合成を行う色空間。線形の Rec.709 | `lin_rec709` |
| 表示変換 | 作業色空間から表示の色空間への変換 | OCIO の display/view |
| 符号化値 | 伝達関数を当てた後の値。線形の対 | `transfer.rs` |
| ベイクする | 変換を 3D LUT に焼いて固定すること | `TransformProgram::Lut3d` |
| 焼き込む | フレームの番号などを画素に書き込むこと（burn-in） | `fixtures/media/generate.sh` |
| ルックアップテーブル | 計算の代わりに引く表 | `transfer.rs` |

## 時間とシーケンス

| 用語 | 定義 | 識別子 |
|---|---|---|
| 時刻 | 有理数で表す時間の位置 | `Time { num, den }` |
| 時間軸 | 時刻をどの座標で測るか（素材、コンポジション、シーケンス） | — |
| 写像（時間の） | コンポジションの時刻と素材の時刻の対応 | `mm_eval::time` |
| シーケンス | カットを順に並べたノード。カットの位置は前のカットのアウト点から決まる（マグネティック） | `sequence`、`place_cuts` |
| イン点 / アウト点 | カットの始まりと終わり | `in`、`out`、`edge` |
| 本編 / ショート | 横長のメインのシーケンス / それを参照または複製した縦のコンポジション | `mm_doc::sequence` |

## 文字

| 用語 | 定義 | 識別子 |
|---|---|---|
| シェーピング | 文字列をグリフの並びにすること | `TextShaper`、`ShapedText` |
