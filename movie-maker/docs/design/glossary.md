# 用語集

設計書、コメント、CLI の文言で使う正式な用語。左が正式な用語、右が定義と対応するコードの識別子。
新しく書くコードと設計書は、最初からこの用語を使う。用語を足すときは、段階ごとの用語のクリーンアップ（[進め方](15-roadmap.md#段階ごとの手順)）で表に足す。
段階の途中の PR は、この表を書き換えず、`glossary.d/<PR の題>.md` に同じ列の表（見出しは足す先の節の名前）で書く。クリーンアップがこの表に移し、そのファイルを消す。用語を引くときは `glossary.d/` も見る。

## 時間とシーケンス

| 用語 | 定義 | 識別子 |
|---|---|---|
| 時刻 | 有理数で表す時間の位置 | `Time { num, den }` |
| 時間軸 | 時刻をどの座標で測るか（素材、コンポジション、シーケンス） | — |

| 再フレーミング | コンポジションごとに、カットの素材のどこを切り出して見せるか（縦の画面で横長の素材の一部を見せる） | `Layer.framing`、`setReframe` |
